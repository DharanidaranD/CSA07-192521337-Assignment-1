### How to run
Python programs require Python 3:
```bash

```

For Packet Tracer tasks, open the `.pkt` file after creating/saving it in Cisco Packet Tracer.  
For Task 10, run the commands in `Task10/measurement_template.txt` on the student's own machine and add the resulting screenshots/capture to the repository.

### Important evidence note
The assignment brief requires the student to individually execute every task and submit real screenshots, Packet Tracer files, Wireshark captures and measurements. This package supplies the calculations, completed code and report draft, but it does **not** invent personal execution evidence. Add your own `.pkt`, `.pcapng`, screenshots and real traceroute/ping outputs before submission.
